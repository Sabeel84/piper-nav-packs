# Piper Nav: map packs and app downloads

Downloads for **Piper Nav**, a free, private, non-commercial offline navigation app for a small group of friends who drive off-road in the UAE desert.

- **Map packs** (release `maps`): offline satellite, road and terrain packs, downloaded from inside the app (Maps screen). Each pack is a set of PMTiles files plus a `catalog.json` index.
- **App** (release `app`): the Android APK and `version.json` used by the in-app "Update available" check.

There is no app store listing and no paid service. The source code is kept private.
